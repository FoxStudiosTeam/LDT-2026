# Инструкция по работе с `dev_pyrails`

Пайплайн детекции рельсов и предсказания кривизны пути работает с дальностными кадрами (`.npy`), отрендеренными сервисом `rust_viewer`.

---

## 1. Подготовка и выгрузка кадров из `rust_viewer`

Чтобы `rust_viewer` сохранял дальностные кадры на хост-машину:

1. **Переменная окружения `RENDER_PATH` в `.env`**:
   Убедитесь, что в файле [`.env`](file:///r:/prog/LDT-2026/.env) задан путь для сохранения кадров:
   ```env
   RENDER_PATH = "/frames"
   TOTAL_FRAMES = 250
   PREVIEW_FOV_X_DEG = 25.0
   ```

2. **Монтирование тома в `compose.yml` (Важно!)**:
   Убедитесь, что у сервиса `rust_viewer` в [compose.yml](file:///r:/prog/LDT-2026/compose.yml) проброшена папка с хоста в контейнер:
   ```yaml
   rust_viewer:
     # ...
     volumes:
       - ./frames:/frames
   ```
   > [!WARNING]
   > Если том `./frames:/frames` не смонтирован, сгенерированные `.npy` файлы останутся внутри файловой системы контейнера и не попадут в папку `frames/` на хосте.

3. **Запуск рендеринга**:
   ```bash
   docker compose up rust_viewer
   ```
   После завершения в папке `frames/` появятся файлы `frame_000001.npy` ... `frame_000249.npy`.

---

## 2. Запуск детектора рельсов (`dev_pyrails`)

Для запуска используется предустановленное виртуальное окружение:

```powershell
# 1. Интерактивный плеер со слайдером (OpenCV GUI)
viewer\venv\Scripts\python.exe dev_pyrails\main.py --interactive

# 2. Пакетная обработка всех кадров с экспортом в MP4 видео
viewer\venv\Scripts\python.exe dev_pyrails\main.py --all --video

# 3. Обработать и сохранить один конкретный кадр (например, поворот на кадре 101)
viewer\venv\Scripts\python.exe dev_pyrails\main.py --frame 101

# 4. Обработать диапазон кадров
viewer\venv\Scripts\python.exe dev_pyrails\main.py --range 80 160 --video
```

---

## 3. Управление в интерактивном режиме (`--interactive`)

- **Ползунок (Slider)** — быстрый переход на любой кадр.
- **`ПРОБЕЛ`** — Старт / Пауза воспроизведения.
- **`D`** или **`Вправо`** — Следующий кадр.
- **`A`** или **`Влево`** — Предыдущий кадр.
- **`S`** — Сохранить скриншот текущего кадра в `dev_pyrails/output/`.
- **`Q`** или **`ESC`** — Выход из просмотрщика.

- **`frame_XXXXXX_composite.png`** — ключевые кадры с наложенной разметкой.
