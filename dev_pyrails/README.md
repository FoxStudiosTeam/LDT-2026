# Rail Track Detection & Trajectory Prediction (Python Prototype)

Прототип алгоритма детекции рельсов и предсказания траектории движения состава по сферическим дальностным кадрам (Range/Depth Images) с лидара **Hesai Pandar 128** (`128x167`, FOV $V: [+15^\circ, -25^\circ]$, $H: 25^\circ$).

---

## Архитектура и структура модулей

```
dev_pyrails/
├── geometry.py        # Векторизованные преобразования сферических координат в 3D (X, Y, Z) и обратно
├── detector.py        # Детекция рельсов, пространственное отслеживание, аппроксимация кривых (3D RANSAC / Polyfit)
├── visualizer.py      # Многопанельный рендеринг: перспективный Range View, карта BEV (сверху) и HUD-телеметрия
├── main.py            # CLI и интерактивный просмотрщик OpenCV со слайдером кадров и видео-экспортом
├── output/            # Сгенерированные видео и ключевые кадры
└── README.md          # Документация
```

---

## Принцип работы алгоритма

1. **3D Проекция и геометрия сенсора (`geometry.py`)**:
   - Каждая строка кадра соответствует фиксированному углу места (pitch от $+15^\circ$ до $-25^\circ$).
   - Каждый столбец соответствует азимуту (yaw от $-12.5^\circ$ до $+12.5^\circ$).
   - По значениям дальности $R$ вычисляются декартовы координаты:
     $$X = R \cos(p) \cos(y), \quad Y = R \cos(p) \sin(y), \quad Z = R \sin(p)$$

2. **Физические маркеры рельсов в скане (`detector.py`)**:
   - Между рельсами находится углубление / балластное корыто глубиной около $35\text{--}38\text{ см}$.
   - При сканировании слева направо по строке:
     - На левом рельсе дальность резко возрастает ($\Delta R > +0.10\text{м}$, вход в углубление).
     - На правом рельсе дальность резко спадает ($\Delta R < -0.10\text{м}$, выход из углубления на грунт).
   - Координаты головок рельсов фиксируются на уровне полотна ($Z \approx -1.45\text{м}\dots -1.85\text{м}$) на внешних гранях перепада.
   - Физическая ширина колеи: жесткий геометрический фильтр $W \in [0.30\text{м}, 0.50\text{м}]$ (номинал $0.38\text{--}0.42\text{м}$).

3. **Отслеживание и аппроксимация траектории (с учетом поворотов)**:
   - Сканирование выполняется снизу вверх (от ближней зоны $X \approx 3.5\text{м}$ к дальней $X > 20\text{м}$) с проверкой пространственной непрерывности.
   - В плоскости пути (BEV) осевая линия аппроксимируется параболой:
     $$Y_c(X) = a X^2 + b X + c$$
   - Вычисляются ключевые навигационные метрики:
     - **Радиус кривизны**: $R = \frac{1}{2 |a|}$
     - **Курсовой угол состава относительно колеи**: $\psi = \arctan(b)$
     - **Боковое смещение от центра**: $c = Y(0)$
     - **Классификация маневра**: `STRAIGHT` ($R > 2500\text{м}$), `CURVE LEFT` ($a < 0$), `CURVE RIGHT` ($a > 0$)
   - Траектории левого и правого рельсов строятся через вектор нормали $\vec{n} = (-\sin\theta, \cos\theta)$:
     $$X_{L,R} = X_c \pm \frac{W}{2}\sin\theta, \quad Y_{L,R} = Y_c \mp \frac{W}{2}\cos\theta$$

4. **Визуализация (`visualizer.py`)**:
   - **Forward Range View**: наложение левого рельса (голубая линия), правого рельса (оранжевая линия), осевой линии (зеленая линия), полупрозрачного коридора габарита пути и отметок дальности ($5\text{м}, 10\text{м}, 15\text{м}, 20\text{м}$).
   - **Bird's Eye View (BEV)**: вид сверху ($X \in [0, 24]\text{м}$, $Y \in [-2.5, +2.5]\text{м}$) с концентрическими кольцами дальности и положением локомотива.
   - **HUD Telemetry**: состояние поворота, радиус кривизны, боковое смещение, ширина колеи, количество валидных строк и качество трекинга.

## Запуск

Используйте виртуальное окружение viewer:
```powershell
# 1. Интерактивный плеер со слайдером (OpenCV GUI)
viewer\venv\Scripts\python.exe dev_pyrails\main.py --interactive

# 2. Обработать все кадры и сгенерировать MP4-видео
viewer\venv\Scripts\python.exe dev_pyrails\main.py --all --video

# 3. Обработать один конкретный кадр (например, кадр 101 - поворот налево)
viewer\venv\Scripts\python.exe dev_pyrails\main.py --frame 101

# 4. Обработать диапазон кадров
viewer\venv\Scripts\python.exe dev_pyrails\main.py --range 50 150 --video
```

### Управление в интерактивном режиме:
- `ПРОБЕЛ` — Воспроизведение / Пауза
- `D` / `Вправо` — Следующий кадр
- `A` / `Влево` — Предыдущий кадр
- `S` — Сохранить скриншот текущего кадра
- `Q` / `ESC` — Выход
- Слайдер в верхней части окна позволяет мгновенно перемещаться на любой кадр.
